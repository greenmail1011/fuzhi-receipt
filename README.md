# 富志科技｜蝦皮購物領據產生器

單一 HTML 頁面：上傳蝦皮訂單截圖 → 填寫領據與細項 → 匯出 A4 PDF 列印。

- 金額自動轉中文大寫，日期用民國年
- 第 1 頁為領據 + 細項表，後續頁為訂單截圖附件
- 所有資料只在瀏覽器本機處理，不會上傳；文字欄位存在 localStorage
- 「✨ 從截圖自動帶入細項」（Claude AI 讀圖）只在 Claude artifact 版本可用
- 獨立開啟（含 GitHub Pages）時，可按「🔍 辨識截圖帶入細項」：用瀏覽器內的 Tesseract.js 本機 OCR（繁中），圖片不上傳；首次需下載約 4 MB 模型，結果可能有錯字，請核對

使用：直接用瀏覽器開啟 `index.html`。

> 請勿將填好的領據 PDF 或訂單截圖 commit 進此 repo（已在 .gitignore 排除）。
